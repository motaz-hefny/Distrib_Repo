# MoTekLab Video Converter (vconv) — Universal Distribution

[![Release](https://img.shields.io/badge/release-latest-blue.svg)](https://github.com/motaz-hefny/MoTekLab-vconv)
[![License: Open Source](https://img.shields.io/badge/license-GPL--3.0-green.svg)](https://github.com/motaz-hefny/MoTekLab-vconv)

**vconv** is a fast, hardware-accelerated video conversion and remuxing utility supporting modern video codecs (AV1, HEVC, H.264) with stream pass-through and chapter preservation.

---

## Features
- Hardware transcoding (NVENC, VAAPI, QSV).
- Lossless remuxing across MP4, MKV, WebM, and MOV containers.
- Subtitle extraction, retention, and burn-in controls.
- Optimized presets for streaming, archiving, and mobile viewing.

# MoTekLab Markdown to Formatted Text Converter

[![Release](https://img.shields.io/badge/release-latest-teal.svg)](https://github.com/motaz-hefny/md-converter)
[![License: Open Source](https://img.shields.io/badge/license-MIT-green.svg)](https://github.com/motaz-hefny/md-converter)

**MoTekLab Markdown to Formatted Text** is a privacy-first web application and utility for converting GitHub-flavored Markdown into clean rich text, formatted HTML, Word documents (.docx), and styled PDFs.

---

## Features
- Full GFM support: tables, task lists, code fences with syntax highlighting, and KaTeX math.
- Native clipboard copy as rich text for Microsoft Word, Outlook, and Google Docs.
- Local execution with zero cloud storage or document caching.

MetaForge APT Repository Setup

Debian, Ubuntu, Pop!_OS, and Linux Mint systems can subscribe to the automated APT repository channel:

# 1. Register the repository source
echo "deb [trusted=yes] https://motaz-hefny.github.io/Distrib_Repo/debian stable main" | sudo tee /etc/apt/sources.list.d/moteklab-metaforge.list

# 2. Update package cache & install
sudo apt update
sudo apt install moteklab-metaforge
